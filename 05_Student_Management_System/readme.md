# 🎓 Student Management System (Python)

A simple **menu-driven Student Management System** built using **Python Fundamentals**. This project helps practice dictionaries, functions, loops, conditionals, and basic CRUD (Create, Read, Update, Delete) operations.

---

## 📌 Features

- ➕ Add Student
- ✏️ Update Student Marks
- ❌ Delete Student
- 🔍 Search Student
- 📋 Display All Students
- 📊 Calculate Average Marks
- 🚪 Exit Program

---

## 🛠️ Technologies Used

- Python 3
- Dictionaries
- Functions
- Loops
- Conditional Statements
- User Input
