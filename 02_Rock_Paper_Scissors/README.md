# ✊✋✌ Rock Paper Scissors Game

## 📌 Overview

A command-line implementation of the classic Rock, Paper, Scissors game.

The player competes against the computer, which makes random choices.

---

## 🚀 Features

- Computer-generated random moves
- Score tracking
- Multiple game rounds
- Win/Lose/Draw detection
- User-friendly interface

---

## 🛠 Technologies Used

- Python
- Random Module

---

## 📚 Concepts Practiced

- Loops
- Conditional Statements
- Functions
- Random Module
- User Input
- Game Logic

---

## ▶️ How to Run

```bash
python main.py
```
