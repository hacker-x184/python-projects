# 🧮 Python Calculator

A simple **menu-driven Calculator** built using **Python Fundamentals**. This project performs basic arithmetic operations while helping practice functions, loops, conditionals, exception handling, and user input.

---

## 📌 Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- 🔄 Continuous Calculations
- ⚠️ Division by Zero Handling
- 🚪 Exit Program

---

## 🛠️ Technologies Used

- Python 3
- Functions
- Loops
- Conditional Statements
- Exception Handling
- User Input

## 🚀 How to Run

1. Clone the repository

```bash
git clone https://github.com/hacker-x184/python-Library.git
```

2. Move into the project directory

```bash
cd python-Library
```

3. Run the program

```bash
python calculator.py
```

## 📖 Example

### Addition

```
Select Operation: +

Enter Number 1: 10
Enter Number 2: 20

Result = 30
```

---

### Multiplication

```
Select Operation: *

Enter Number 1: 12
Enter Number 2: 5

Result = 60
```

---

### Division

```
Select Operation: /

Enter Number 1: 100
Enter Number 2: 20

Result = 5.0
```

---

### Division by Zero

```
Select Operation: /

Enter Number 1: 50
Enter Number 2: 0

Error: Division by zero is not allowed.
```
