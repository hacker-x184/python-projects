# 🎯 Number Guessing Game

## 📌 Overview

A simple command-line Number Guessing Game built with Python.

The player tries to guess a randomly generated number within a limited number of attempts.

---

## 🚀 Features

- Random number generation
- User input validation
- Unlimited/Limited attempts (depending on implementation)
- Hint system (Higher/Lower)
- Winning and losing messages

---

## 🛠 Technologies Used

- Python
- Random Module

---

## 📚 Concepts Practiced

- Variables
- Loops
- Conditional Statements
- User Input
- Random Numbers
- Problem Solving

---

## ▶️ How to Run

```bash
python main.py
```
