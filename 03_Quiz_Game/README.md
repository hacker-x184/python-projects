# 🧠 Python Quiz Game

## 📌 Overview

A simple command-line quiz application built using Python.

The player answers multiple-choice or text-based questions, and the program calculates the final score.

---

## 🚀 Features

- Multiple quiz questions
- Score calculation
- Correct/Incorrect answer validation
- Final score display
- Interactive gameplay

---

## 🛠 Technologies Used

- Python

---

## 📚 Concepts Practiced

- Variables
- Conditional Statements
- Loops
- Functions
- User Input
- Lists & Dictionaries

---

## ▶️ How to Run

```bash
python main.py
```

This project helped me practice user interaction, logical decision-making, score tracking, and Python programming fundamentals.
